Coimbatore multi-year LULC dashboard
===================================

This folder reuses the already computed Coimbatore classification outputs for
2019 through 2026. No Earth Engine recomputation is required to use the
dashboard.

Open index.html in a browser to:
- compare any two years side by side;
- overlay the current year on the baseline year with adjustable opacity;
- browse all eight yearly PNG outputs;
- open the original Earth Engine script and GeoTIFF exports.

The Earth Engine source is Code.txt. If the classifications need to be
regenerated, run that script in the Google Earth Engine Code Editor and export
the resulting images at 50 m using the existing export function.
